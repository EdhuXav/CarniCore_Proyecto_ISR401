# 00_Restringido — Evidencias con acceso restringido

Los archivos `.7z` de esta carpeta contienen evidencias del proyecto
(entrevistas y material de respaldo) que incluyen información sensible
o de identificación de las personas participantes.

## Contenido protegido

Por motivos de confidencialidad y ética de la investigación, estos
archivos están comprimidos con **contraseña** y **no deben abrirse ni
distribuirse fuera del equipo del proyecto**.

## Cómo extraerlos

1. Descarga el archivo `.7z` correspondiente.
2. Ábrelo con **WinRAR** (o 7-Zip).
3. Ingresa la contraseña correspondiente cuando se solicite.
4. La contraseña es entregada únicamente al equipo del proyecto por un
   canal aparte (no se publica en este repositorio).

## Nota

Si no cuentas con la contraseña, no tienes acceso autorizado a este
contenido. Contacta al equipo del proyecto para solicitarla si tu rol
lo requiere.
